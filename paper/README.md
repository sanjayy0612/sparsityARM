# Paper package

`main.tex` is the canonical manuscript. Figure data (`figures/*.dat`) and
tables (`tables/*.tex`) are generated by `research_tools/package_results.py`
from committed, validated experiment artifacts; figures are drawn with
pgfplots from that data. The SVGs in `figures/` are used by the repository
README only.

The manuscript needs no shell escape or external tools, so it compiles
unchanged on Overleaf, arXiv, or any TeX Live installation:

```bash
tectonic -X compile main.tex        # or: pdflatex main && bibtex main && pdflatex main && pdflatex main
```

`arm-sparse-report.pdf` is compiled from these sources.
