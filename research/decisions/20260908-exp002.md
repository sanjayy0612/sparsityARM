# EXP-002 scope

The user requested continuing the research after EXP-001 identified loss of
sparsity under block expansion. Proceed with the previously proposed real-mask
coverage measurement on the primary Llama 3.2 1B model. The official checkpoint
is accessible at revision 4e20de362430cd3b72f300e6b0f18e50e7166e08.

Use CPU BF16 capture to limit memory on the 8 GiB M2. This is a separate
activation-coverage experiment, not a change to EXP-001's FP32 performance
methodology. Teacher-forced prefill supplies real causal contexts cheaply;
neither generation speed nor quality will be claimed. Eight fixed prompts and
all layers provide an initial locality screen, not a representative evaluation.

The reference mask ranks absolute actual SwiGLU activations. It does not use
the older gate-preactivation score, and it is not an optimal selector. Measure
expansion, a permutation control, and direct block selection separately.

No predictor, model training, neuron reordering, manuscript, cross-hardware
claim or new sparsity strategy is approved or implemented by this decision.
